This directory is reserved for Home Assistant package YAML files.

Suggested future files:
- `bedroom.yaml` for bedroom scenes, helpers, and automations
- `bathroom.yaml` for bathroom-specific logic
- `presence.yaml` for occupancy or schedule helpers

Keep entity-specific YAML here only after the real entity IDs exist in Home Assistant.

You can also start from `mia_starter_package.example.yaml` as a commented template.
